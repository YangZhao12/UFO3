# UFO³ Installation Tutorial

## Architecture

The deployment consists of three components:

- **Host**: Runs the UFO Server and Galaxy WebUI.
- **Tunnel Service**: Exposes the Host service (`localhost:5000`) to the public internet.
- **Proxy (Agent Device)**: Connects to the Host through the public endpoint and executes automation tasks.

---

## Prerequisites

### Optional: Create a Conda Environment

```bash
conda create -n ufo python=3.10
conda activate ufo
```

### Clone the Repository

```bash
git clone https://github.com/microsoft/UFO.git
cd UFO
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

---

# Step 1: Start the Host

Launch the UFO Server on the host machine:

```bash
python -m ufo.server.app --port 5000
```

The UFO Server will listen on:

```text
http://localhost:5000
```

## Expose the Host Service

Since the Proxy device needs to access the Host remotely, a tunnel service is required to map `localhost:5000` to a public URL.

### Example: Using Cloudflare Tunnel

```bash
cloudflared.exe tunnel --url http://localhost:5000
```

After the tunnel is created, Cloudflare will generate a public URL similar to:

```text
https://restored-momentum-ann-palace.trycloudflare.com
```

This URL will be used by the Proxy device to connect to the Host.

For more information, refer to the UFO³ proxy configuration documentation.

---

# Step 2: Start the Proxy

Run the following command on the agent device:

```bash
python -m ufo.client.client \
  --ws \
  --ws-server wss://restored-momentum-ann-palace.trycloudflare.com/ws \
  --api-key "YOUR_UFO_SERVER_API_KEY" \
  --client-id windows_device_1 \
  --platform windows
```

## Parameters

| Parameter | Description |
|------------|-------------|
| `--ws` | Enable WebSocket communication |
| `--ws-server` | Public WebSocket endpoint exposed by the Host |
| `--api-key` | API key generated by the UFO Server |
| `--client-id` | Custom name of the agent device |
| `--platform` | Operating system of the agent device |

### Example

```bash
python -m ufo.client.client \
  --ws \
  --ws-server wss://restored-momentum-ann-palace.trycloudflare.com/ws \
  --api-key "xxxxxxxxxxxxxxxxxxxx" \
  --client-id windows_device_1 \
  --platform windows
```

---

# Step 3: Configure Device Information

Before launching Galaxy WebUI, configure the device information in:

```text
config/galaxy/devices.yaml
```

Add the registered Proxy devices to this file according to the UFO³ documentation.

For details, refer to:

```text
Devices - UFO³ Documentation
```

---

# Step 4: Launch Galaxy WebUI

After the device configuration is completed, start Galaxy WebUI:

```bash
python -m galaxy --webui
```

Once the service starts successfully, open the WebUI in your browser and begin managing automation tasks.

# Quick Start

```bash
# Host
python -m ufo.server.app --port 5000

# Tunnel
cloudflared.exe tunnel --url http://localhost:5000

# Proxy
python -m ufo.client.client \
  --ws \
  --ws-server <PUBLIC_WS_URL>/ws \
  --api-key "<API_KEY>" \
  --client-id windows_device_1 \
  --platform windows

# Galaxy UI
python -m galaxy --webui
```
